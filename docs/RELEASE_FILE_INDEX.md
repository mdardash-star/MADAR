### Access Points

|---------|-----|---------|
| Frontend | http://localhost:3000 | Web application |
| API | http://localhost:8000 | REST API base |
| Swagger Docs | http://localhost:8000/docs | Interactive API docs |
| ReDoc | http://localhost:8000/redoc | Alternative API docs |
| PostgreSQL | localhost:5432 | Database |
| Redis | localhost:6379 | Cache/sessions |

### Quick Commands

```bash
# Setup
git clone https://github.com/mdardash-star/MADAR.git && cd MADAR
cp .env.example .env && cp apps/api/.env.example apps/api/.env

# Start
docker compose up --build -d

# Initialize
docker compose exec api alembic upgrade head
docker compose exec api python scripts/seed_sample_data.py

# Verify
curl http://localhost:8000/health

# Stop
docker compose down
```
