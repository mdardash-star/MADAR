## 1. Pricing Philosophy

MADAR uses a **per-seat, per-company SaaS model** with:
- No setup fees
- Monthly or annual billing (annual = 2 months free)
- 14-day free trial, no credit card required
- Transparent pricing, no hidden costs
- Self-service upgrade/downgrade

## 7. Billing Implementation

### Payment Processors
- **Primary**: Stripe (global coverage, supports SAR, AED, USD)
- **MENA**: Hyperpay or Moyasar (for local card networks)
- **Invoicing**: Stripe Invoicing for annual plans

### Metering & Usage
- Track per-company: user count, storage used, API calls
- Hard limits enforced at API gateway level
- Soft limits trigger in-app upgrade prompts
- Grace period: 7 days over limit before service restriction

### Trial Conversion Flow
1. Register → 14-day trial (Growth tier features)
2. Day 7: In-app prompt to add payment method
3. Day 12: Email reminder
4. Day 14: Downgrade to Starter if no upgrade
5. Data retained for 90 days after downgrade
